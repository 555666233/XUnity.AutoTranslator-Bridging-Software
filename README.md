# Unity自动翻译对接软件

> 专为中文翻译而生，为 XUnity.AutoTranslator 注入 AI 大语言模型的灵魂。

## 🎯 项目简介

本项目是一个中转对接软件，旨在桥接 **XUnity.AutoTranslator** 插件与强大的 **AI 大语言模型** 翻译服务。它针对将游戏文本翻译为中文进行了深度优化和定制，旨在为玩家提供远超传统翻译引擎的、更加准确、流畅且符合语境的翻译体验。

> **请注意：** 本项目**只针对**将游戏文本翻译为中文的使用场景！

## ✨ 特性亮点

- **🤖 AI 大模型驱动**：无缝对接所有类 OpenAI 接口的大语言模型，可以随着 AI 的发展不断获得更好的翻译结果。
- **🎯 中文深度优化**：专门针对翻译为中文进行调优，特别是日译中、英译中，提高翻译速度，强化翻译质量。
- **📖 支持术语表功能**：支持自定义术语表，确保特定角色名、地名、技能、物品等专有名词在整个游戏中的翻译保持一致。
- **⚡ 一键提取游戏术语**：游戏中一键提取最近文本中的角色名、地名，动态保存生效，更便捷地管理和更新术语表。
- **📊 操作界面简洁美观**：提供清晰的配置指南，只需简单几步即可完成与 XUnity.AutoTranslator 插件、与 AI 大语言模型的对接。
