# Unity自动翻译对接软件（Unity引擎游戏汉化工具）

> 一款专注于 **小而精** 的自动化游戏汉化翻译工具，专为中文翻译而生，为 XUnity.AutoTranslator 注入 AI 大语言模型的灵魂。

## 🎯 项目简介

本项目是一个兼顾中转对接的 **免费** 游戏翻译软件，旨在桥接 **XUnity.AutoTranslator** 插件与强大的 **AI 大语言模型** 翻译服务，并提供一系列有助于游戏文本汉化相关的**拓展功能**支持。它针对将游戏文本翻译为中文进行了深度优化和定制，旨在为玩家提供远超传统翻译引擎的、更加准确、流畅且符合语境的翻译体验。

> **请注意：** 本项目**只针对**将游戏文本翻译为中文的使用场景！

## ✨ 特性亮点

- **📊 界面简洁，操作简单**：提供清晰的配置指南，支持一键自动安装插件、一键卸载插件等便捷功能，只需简单几步即可完成与 XUnity.AutoTranslator 插件、与 AI 大语言模型的双向对接。
- **🤖 AI 大模型驱动**：无缝对接所有类 OpenAI 接口的大语言模型，包括本地部署的免费开源模型（如Sakura模型、qwen模型等），可以随着 AI 的发展不断获得更好的翻译结果。
- **📈 支持并发**：支持并发翻译，提高翻译速度。
- **🎯 中文深度优化**：专门针对翻译为中文进行调优，特别是日译中、英译中，强化翻译质量。
- **📖 术语表定制**：支持自定义术语表，确保特定角色名、地名、技能、物品等专有名词在整个游戏中的翻译保持一致。
- **⚡ 一键提取游戏术语**：游戏中支持一键提取最近文本中的角色名、地名，动态保存生效，更便捷地提取术语。
- **📝 人工汉化校对**：支持边玩边人工校对翻译结果、修正译文格式、重新发起AI翻译等进阶汉化操作。
- **🎮 游戏管理**：统一管理本地电脑里的所有Unity游戏，支持打分、打标签、游玩计时，一键游玩游戏！
